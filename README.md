# Ultra low power BLE link layer
This repo is about an implementation of ultra low power BLE Link Layer. It shows how to use Unified Power Formal (UPF) to define multiple power domains and how to handle signal crossing between domains using different strategies like isolations and retentions.

## Repo structure
 - you can find all neccessary info in the docs directory. The main one is `architecture.md`. It shows an overall view of the design as well as many detailes of selected strategies.
 - The `rtl` directory contains all digital design implementation in system verilog.
 - The `upf` directory contains the upf file and the report generated by open source tools.
 - All testbenches are in `tb` directory and you can run them using scripts inside `script` directory.
